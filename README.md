# Voice Tools

A macOS menu bar app for dictation and read-aloud, built from **tracks**: hotkey-triggered pipelines
(on-device Parakeet transcription, cloud transcription and cleanup, read selected text aloud, and more).

This repository holds only the releases and the update feed the app checks.

## Install

1. Download `Voice-Tools-<version>-arm64.zip` from the [latest release](https://github.com/brancusi/voice-tools-releases/releases/latest) and unzip it.
2. Move **Voice Tools.app** to Applications.
3. The app isn't notarized yet, so the first time: **right-click → Open → Open**. After that it opens normally.
4. It lives in the menu bar (the mic icon). Grant **Microphone** and **Accessibility** when asked; the panel's
   Checks list shows anything still missing.

After that it keeps itself up to date: the menu bar icon turns into a download arrow and the panel offers **Install…**.

Apple silicon, macOS 14 or later.
